Found it. The panel accent falls back to the default theme whenever a room's config hasn't arrived yet — and on reload the panel mounts before the fetch resolves:
tsx web/src/App.tsx 6 lines 
accent={
  focusMode
    ? '#8f8f8f' // focus grays the trim too
    : (THEMES.find((t) => t.id === configs[panelRoomId]?.theme)?.accent
      ?? THEMES[0].accent)  // ← first paint: configs is still {}
}
Two clean fixes: hold the trim until configs resolve, or cache each room's last theme in localStorage and seed from that. The cache kills the flash outright and costs one line on write.
